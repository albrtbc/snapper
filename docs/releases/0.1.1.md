## Hide the overlay when switching apps

Enable **Hide panels when Marvel Snap is not focused** under **Settings → Panels**
and click **Save settings**. Panels hide while another application is active and
return when you switch back to Marvel Snap. You can still interact with Snapper.
Cards, match history and your manual hide setting are preserved.

The option is off by default. Focus detection supports Hyprland and X11 desktops.
On other Wayland desktops, settings reports that focus detection is unavailable;
leave the option off there.

Download the new AppImage and choose **Install** to update. Settings and artwork
caches are preserved. The Linux x86-64 package still requires Python 3 and an
X11/XWayland desktop. The automatic game-start behavior is unchanged.
