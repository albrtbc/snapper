First Linux x86-64 AppImage release of Snapper.

- Own-deck and revealed-opponent tracking, with cards retained through the results screen.
- Deck and hand counts in the panel headers, leaving more room for cards.
- Noncommercial use and modification under PolyForm Noncommercial 1.0.0.
- Per-user installation, application-menu entry and automatic startup with Marvel Snap.

## Install

Download `Snapper-0.1.0-linux-x86_64.AppImage`, make it executable and open it.
Choose **Install** to enable automatic startup. Node.js and a source checkout are
not required. **Run once** keeps it portable.

```sh
chmod +x Snapper-0.1.0-linux-x86_64.AppImage
./Snapper-0.1.0-linux-x86_64.AppImage --appimage-extract-and-run --install
```

The command also works without FUSE. Installation copies the application into
`~/.local/share/snapper/` and creates `~/.local/bin/snapper` and a login watcher.
The watcher starts immediately and at subsequent desktop logins. It opens the
overlay when Marvel Snap starts and closes it when the game exits. Quitting the
overlay manually leaves it closed until the next game session.

Requires Python 3, libX11, libXext and an X11/XWayland desktop. Live tracking
supports the pinned Marvel Snap 57.17 Linux/Proton build. AppImage does not provide
Windows/macOS support or remove compositor and process-access restrictions.

To update, download a newer AppImage and choose **Install** again. To uninstall:

```sh
~/.local/bin/snapper --uninstall
```

Settings and artwork caches are preserved. Verify downloaded files with
`sha256sum -c SHA256SUMS` after downloading both listed archives. Checksums verify
file integrity; this release has no publisher signature or automatic updater.
