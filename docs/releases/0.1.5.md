## Support Marvel Snap 59.15.1

The Marvel Snap 59.15.1 update stopped live tracking. The overlay showed only
your deck, with no hand count and no opponent panel, and the settings button
warned "Unsupported Marvel Snap build". Snapper reads the new build again: the
hand and deck counters, played and discarded cards, **Added** and the opponent
panel follow the match as before.

Live tracking supports Marvel Snap 59.15.1 on Linux/Proton. Build 58.15.1 is no
longer supported.

Download the new AppImage and choose **Install** to update. Settings and artwork
caches are preserved. The Linux x86-64 package still requires Python 3 and an
X11/XWayland desktop.
