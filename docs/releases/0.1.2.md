## Support Marvel Snap 58.15.1

Marvel Snap 58.15.1 changed the game data that Snapper reads. Since that update,
live tracking stopped without a warning. Only your selected deck appeared, the
Hand counter stayed empty, drawn and played cards were not marked, and the
opponent panel never opened. Snapper now reads 58.15.1 again: both panels follow
the match as before.

Each Snapper release supports specific Marvel Snap builds. When a game update
arrives before a Snapper release, Snapper now tells you instead of failing
silently:

- The settings button in the panel header turns into a warning. Its tooltip
  explains why.
- **Settings** and the tray menu show "Unsupported Marvel Snap build".

The same warning appears when Linux denies access to the game's state.

Live tracking supports Marvel Snap 58.15.1 on Linux/Proton. Builds 57.17 and
older are no longer supported.

Download the new AppImage and choose **Install** to update. Settings and artwork
caches are preserved. The Linux x86-64 package still requires Python 3 and an
X11/XWayland desktop.
